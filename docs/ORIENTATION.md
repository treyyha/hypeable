# Orientation

Chat/LLM: the client (`app/components/chat/Chat.client.tsx`) posts via `useChat` to `/api/chat`; that route streams through `app/lib/.server/llm/stream-text.ts`. Extra LLM hops are `/api/llmcall` and `/api/enhancer`.

API keys live in `localStorage` (or `sessionStorage` if "forget keys when I close the tab" is on). On LLM routes they are sent per request in `x-hypeable-key`. Selected provider/model, the composer draft, agent mode, debug flags, and event logs are also `localStorage` (`hypeable:pref:*`, `hypeable:eventLogs`) — not cookies. See `docs/KEY-FLOW.md`. Theme/profile sit in `localStorage` (`bolt_theme`, `bolt_user_profile`).

Header/logo: `app/components/header/Header.tsx` (images `/logo-light-styled.png` and `/logo-dark-styled.png`, which are currently missing). Favicon is `/favicon.svg` from `app/root.tsx`. Landing copy is in `HomeHero` / `BaseChat`. First-run onboarding is the SSR `StartInSixty` card on home (dismissed via `localStorage` `bolt_onboarding_completed`, never a cookie). Home chrome is in the first HTML and stays mounted until a build starts. Chat loads on composer intent as a headless island; Menu loads on sidebar or settings intent.

Server routes: declared in `app/routes.ts` — pages `/`, `/chat/:id`, `/spend`, `/privacy`, `/terms`, `/git`, `/starter`, `/webcontainer/preview/:id`; unmatched URLs render a branded 404. APIs `/api/chat`, `/api/llmcall`, `/api/enhancer`, `/api/models`, `/api/models/:provider`, `/api/check-env-key`, `/api/configured-providers`, `/api/export-api-keys`, `/api/mcp-check`, `/api/mcp-update-config`, `/api/update`, `/api/bug-report`, `/api/health`, `/api/web-search`, git/GitHub/GitLab/Netlify/Vercel/Supabase proxies, and `/api/system/*`. `/webcontainer/connect/:id` is 404. HTML and static assets get COEP `credentialless`, COOP `same-origin`, Permissions-Policy, enforcing CSP, and a stricter CSP-Report-Only (`app/entry.server.tsx`, `public/_headers`). `/api/*` gets nosniff, Referrer-Policy, and `Cache-Control: no-store` only (`workers/app.ts`). See [DEPLOY.md](DEPLOY.md) and [SECURITY.md](SECURITY.md). On hosted, MCP / bug-report / update / system / git-info / check-env-key / configured-providers return 404; custom LLM endpoints are rejected (`app/lib/security/outbound.ts`).

Theme colours: tokens in `app/styles/tokens.scss` (`--hype-*` maps onto `--bolt-elements-*`). Only **dark** and **light** palettes exist (`app/types/theme.ts`). Stored key is `bolt_theme`; leftover ids such as `dark-nord` normalize to dark or light.

Hypeable does not phone home. `checkForUpdates` is a stub and does not fetch GitHub. Fonts are self-hosted (`@fontsource` Geist). Connector brand marks use Phosphor icons, not `cdn.simpleicons.org`. Performance metrics stay in memory (`app/lib/performance/metrics.ts`). WebContainer (`*.webcontainer-api.io`) boots only after a first build or workbench open — needed, not telemetry. The plugin marketplace tab is hidden (it fetched unvetted third-party zips). Hosted first load does not call `/api/configured-providers` or `/api/check-env-key`. HTML documents send `Cache-Control: no-store, no-transform` so Cloudflare cannot inject `static.cloudflareinsights.com`. Also disable Web Analytics in the Cloudflare account dashboard (Analytics & logs → Web Analytics → Manage site → Disable). LICENSE/NOTICE keep upstream credit. There is no Electron/desktop app. No Discord, no PostHog.
